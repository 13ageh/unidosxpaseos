# Unidos por Paseos — Demo Frontend

Demo pública (visitante no registrado) para mostrar la página de la
asociación vecinal Paseos del Sol, Segunda Sección.

## Cómo verlo en localhost

### Opción A — Apache / XAMPP / MAMP
Coloca la carpeta `unidos-por-paseos/` dentro de tu `htdocs` o `www`
y abre:
http://localhost/unidos-por-paseos/

### Opción B — Servidor simple con Python
Desde la carpeta del proyecto:
python3 -m http.server 8000
y abre: http://localhost:8000

### Opción C — VS Code Live Server
Click derecho sobre `index.html` → "Open with Live Server".
